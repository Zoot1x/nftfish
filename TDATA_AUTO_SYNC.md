# 🔄 Автоматическая синхронизация TData

## Обзор

Система теперь автоматически переносит TData файлы с backend в бота после их конвертации и удаляет их после выгрузки архива. Это предотвращает повторную выгрузку одних и тех же данных.

## Компоненты

### 1. Backend: `convert_sessions.py`

#### Новая функция: `copy_tdata_to_bot()`

```python
def copy_tdata_to_bot(tdata_path: str, country_code: str = None) -> bool:
    """Копирует tdata папку в admin-bot/tdatas/COUNTRY_CODE/ папку."""
```

**Что делает:**
- Получает папку с номером телефона из пути
- Копирует содержимое папки tdata в `admin-bot/tdatas/COUNTRY_CODE/PHONE_NUMBER/`
- Сохраняет иерархию папок внутри
- Отправляет уведомление о успехе

**Вызывается в:**
- `convert_session_to_tdata()` - после успешной конвертации
- Fallback процесс - даже если конвертация частичная

**Пример структуры:**
```
Backend создает:
  results/session_to_tdata/tdatas/9123456789/tdata/
  ├── session.dat
  ├── cookies.json
  └── state.bin

Копируется в бота:
  admin-bot/tdatas/ru/9123456789/
  ├── session.dat
  ├── cookies.json
  └── state.bin
```

#### Обновленные уведомления

Теперь сообщения содержат информацию о копировании:

**При успехе:**

### 2. Admin Bot: `admin-bot/utils/tdata_service.py`

#### Новые методы удаления

**`delete_archived_folders(country_code)`**
```python
@classmethod
def delete_archived_folders(cls, country_code: str) -> bool:
    """Delete all tdata folders for a country after archiving."""
```

**Что делает:**
- Получает все папки в `tdatas/COUNTRY_CODE/`
- Удаляет каждую папку рекурсивно
- Логирует удаленные папки
- Возвращает количество удаленных папок

**`delete_all_archived_folders()`**
```python
@classmethod
def delete_all_archived_folders(cls) -> bool:
    """Delete all tdata folders from all countries after archiving."""
```

**Что делает:**
- Вызывает `delete_archived_folders()` для каждой страны
- Удаляет TData из всех стран одновременно
- Возвращает True если что-то удалено

### 3. Admin Bot: `admin-bot/handlers/tdata.py`

## Рабочий процесс

### 1️⃣ Получение сессии

```
Пользователь → Frontend → Backend API
   ↓
Сессия сохранена в: backend/sessions/COUNTRY_CODE/
```

### 2️⃣ Конвертация сессии

```
Backend запускает: convert_sessions.py
   ↓
Конвертирует: .session → tdata/
   ↓
Сохраняет в: results/session_to_tdata/tdatas/PHONE_NUMBER/tdata/
   ↓
Уведомление: "⏳ Статус: начинаю конвертацию..."
```

### 3️⃣ Копирование в бота (НОВОЕ)

```
copy_tdata_to_bot() вызывается автоматически
   ↓
Копирует в: admin-bot/tdatas/COUNTRY_CODE/PHONE_NUMBER/
   ↓
Уведомление: "🤖 Скопирован в бота для выгрузки"
```

### 4️⃣ Выгрузка архива (ВРУЧНУЮ)

```
Администратор нажимает: "📦 Экспорт TData" в боте
   ↓
Выбирает страну: "RU"
   ↓
Система создает: tdata_ru_20251116_120000.zip
   ↓
Архив содержит: все папки в tdatas/ru/
   ├── ru/9123456789/session.dat
   ├── ru/9123456789/cookies.json
   ├── ru/9987654321/session.dat
   └── ru/9987654321/state.bin
```

### 5️⃣ Удаление после выгрузки (НОВОЕ)

```
После создания архива:
   ↓
delete_archived_folders('ru') вызывается автоматически
   ↓
Удаляет: admin-bot/tdatas/ru/9123456789/
         admin-bot/tdatas/ru/9987654321/
   ↓
Уведомление: "🗑️ Папки будут удалены после выгрузки"
```

### 6️⃣ Повторная защита

```
Если пользователь загружает НОВУЮ сессию:
   ↓
copy_tdata_to_bot() создает: admin-bot/tdatas/ru/9123456789/ (новая!)
   ↓
Старая удаленная папка не восстанавливается
   ↓
Архив может быть создан повторно с НОВЫМИ данными
```

## Troubleshooting

### ❌ "Нет доступных tdata файлов для экспорта"

**Причины:**
- Еще не загружены сессии
- Все файлы уже выгружены и удалены
- Папки находятся в неправильном месте

**Решение:**
1. Проверить `admin-bot/tdatas/` структуру
2. Убедиться, что backend скопировал файлы
3. Проверить `backend/results/session_to_tdata/converter.log`

### ❌ "Ошибка при копировании tdata в bot"

**Причины:**
- Папка `admin-bot/tdatas/` не существует
- Недостаточно прав доступа
- Проблема с путями

**Решение:**
1. Создать папку: `mkdir -p admin-bot/tdatas/ru admin-bot/tdatas/us`
2. Проверить права: `chmod 755 admin-bot/tdatas`
3. Проверить логи: `cat backend/results/session_to_tdata/converter.log`

### ❌ Папки не удаляются после архивирования

**Причины:**
- Недостаточно прав на удаление
- Файлы используются другим процессом
- Ошибка в коде

**Решение:**
1. Проверить права: `ls -la admin-bot/tdatas/`
2. Убедиться, что нет открытых файлов
3. Посмотреть логи бота: `tail -f admin-bot/logs/bot.log`
