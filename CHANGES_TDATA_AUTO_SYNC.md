### 2. `admin-bot/utils/tdata_service.py`

#### Добавлены 2 новых метода:

**`delete_archived_folders(country_code: str) -> bool`**
```python
"""Delete all tdata folders for a country after archiving."""

Что делает:
- Получает все папки в tdatas/COUNTRY_CODE/
- Удаляет каждую папку рекурсивно
- Логирует результат
- Возвращает True если что-то удалено

Пример:
  TdataService.delete_archived_folders('ru')
  # Удалит все папки в admin-bot/tdatas/ru/
```

**`delete_all_archived_folders() -> bool`**
```python
"""Delete all tdata folders from all countries after archiving."""

Что делает:
- Перебирает все страны в tdatas/
- Вызывает delete_archived_folders() для каждой
- Логирует итоги
- Возвращает True если что-то удалено

Пример:
  TdataService.delete_all_archived_folders()
  # Удалит папки из всех стран сразу
```

## 🛡️ Безопасность

1. **Защита от случайного удаления**
   - Удаление происходит ТОЛЬКО после успешного архивирования
   - Логирование всех операций удаления

2. **Защита от повторной выгрузки**
   - Папки удаляются после архивирования
   - Новые загрузки создают новые папки
   - Старые удаленные папки не восстанавливаются

3. **Отслеживание**
   - Каждая операция логируется
   - Telegram уведомления о каждом этапе
   - API endpoint для проверки статуса

## ❓ FAQ

**Q: Когда удаляются папки?**
A: Сразу после создания архива, при нажатии на страну в меню экспорта.

**Q: Можно ли отменить удаление?**
A: Нет, удаленные папки не восстанавливаются. Но архив сохранен на диске.

**Q: Что если копирование с backend не произошло?**
A: Будет ошибка в логах `converter.log`, уведомление придет в Telegram.

**Q: Как проверить статус вручную?**
A: `curl http://localhost:3001/api/tdata/status`

**Q: Можно отключить автоудаление?**
A: Да, закомментировать вызовы `delete_archived_folders()` в `handlers/tdata.py`
