# Admin Bot для Gift Spin Wheel

Отдельный Telegram-бот для администрирования и просмотра статистики.

## 📋 Возможности

- **📊 Статистика логов** 
  - По времени (сегодня, неделя, месяц, все время)
  - По странам (сегодня, неделя, месяц, все время)
  - Успешность конвертации
  - Подсчет ошибок и fallback операций

- **💰 Продажа** (в разработке)

- **🎯 Удобная навигация**
  - Inline кнопки для быстрого доступа
  - Кнопки "Назад" на каждом экране

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd admin-bot
pip install -r requirements.txt
```

### 2. Конфигурация

Отредактируйте файл `.env`:

```bash
# Получите токен у @BotFather в Telegram
ADMIN_BOT_TOKEN=your_bot_token_here

# Ваш Telegram User ID (получите с помощью @userinfobot)
ADMIN_USER_ID=your_user_id_here

# URL бэкенда (опционально)
BACKEND_URL=http://localhost:3001
```

### 3. Запуск бота

```bash
python bot.py
```

## 🔧 Расширение функционала

### Добавить новый обработчик

1. Создайте файл в `handlers/`
2. Определите роутер и функции-обработчики
3. Включите роутер в `bot.py`:

```python
from handlers import your_handler
dp.include_router(your_handler.router)
```

### Добавить новую кнопку

1. Добавьте callback в `utils/callbacks.py`
2. Создайте функцию клавиатуры в `utils/keyboards.py`
3. Добавьте обработчик в соответствующий `handlers/*.py`

## 🔐 Безопасность

- Бот доступен только администратору (ADMIN_USER_ID)
- Токен хранится в `.env` (не коммитится в git)
- Логирование всех операций

## 📝 Логирование

Лог-файл расположен в:
```
backend/results/session_to_tdata/converter.log
```

Бот автоматически читает и анализирует этот файл для статистики.

## 🐛 Отладка

Если бот не отвечает:

1. Проверьте токен в `.env`
2. Убедитесь, что ADMIN_USER_ID правильный
3. Проверьте логи запуска:
   ```bash
   python bot.py
   ```

## 📞 Поддержка

Для добавления новых функций обновите:
- Обработчики в `handlers/`
- Кнопки в `utils/keyboards.py`
- Callback данные в `utils/callbacks.py`
