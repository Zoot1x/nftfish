# 💰 Система продажи - Руководство пользователя

## Быстрый старт

### 1️⃣ Открытие меню продажи

```
Главное меню
    ↓
Нажмите: 💰 Продажа
```

Вы увидите меню с двумя опциями:
- **🟢/🔴 Автопродажа** - включение/отключение автоматических продаж
- **🌍 Продать по странам** - ручная продажа по странам

---

## Автопродажа 🔄

### Как использовать:

1. Нажмите на кнопку **Автопродажа**
2. Кнопка изменит цвет:
   - **🟢 Автопродажа** = включена (зелёный круг)
   - **🔴 Автопродажа** = отключена (красный круг)
3. Состояние автоматически сохраняется

### Текущее состояние:

Состояние хранится в файле: `data/sales_state.json`

```json
{
  "auto_sales_enabled": true,
  "sales_log": [...]
}
```

### Примеры:

| Действие | Кнопка до | Кнопка после | Состояние |
|----------|-----------|-------------|-----------|
| Включить | 🔴 | 🟢 | Сохранено |
| Отключить | 🟢 | 🔴 | Сохранено |

## Продажа по странам 🌍

### Пошаговый процесс:

#### Шаг 1: Выбор страны

```
Нажмите: 🌍 Продать по странам
    ↓

  🇺🇸 United States

  🇬🇧 United Kingdom
  🇩🇪 Germany

Например, нажмите `🇷🇺 Russia`

```

#### Шаг 4a: Если нажали ✅ Продать

```

🇷🇺 Russia: 1 шт.

Возвращаем в меню продажи...
```

Продажа записана в `data/sales_state.json`:

```json
{
  "timestamp": "2025-11-16T04:16:59.538107",
  "country": "Russia",
  "amount": 1.0,
  "status": "completed"
}
```

#### Шаг 4b: Если нажали ❌ Отменить

```
Возврат к выбору страны
```

## Часто задаваемые вопросы ❓

### Q: Где сохраняются данные о продажах?
**A:** В файле `admin-bot/data/sales_state.json` в JSON формате.

### Q: Если я перезагрузу бота, сохранится ли состояние автопродажи?
**A:** Да! Состояние сохраняется в файле и восстанавливается при перезагрузке.

### Q: Могу ли я отредактировать истории продаж вручную?
**A:** Да, файл `sales_state.json` - обычный текстовый JSON файл.

### Q: Сколько стран поддерживается?
**A:** 36 стран, каждая с собственным флагом 🏳️

### Q: Что если я нажму ❌ Отменить при подтверждении?
**A:** Продажа не будет записана, вы вернётесь к выбору страны.

### Q: Можно ли продать нескольким странам одновременно?
**A:** Нет, пока система поддерживает одну продажу за раз. Используйте автопродажу для автоматизации.

### Q: Видны ли продажи в статистике логов?
**A:** Нет, продажи и статистика логов - это отдельные системы. Продажи хранятся в `sales_state.json`, логи в `converter.log`.

## Техническая информация 🛠️

### Структура файла sales_state.json

```json
{
  "auto_sales_enabled": boolean,
  "sales_log": [
    {
      "timestamp": "ISO 8601 формат",
      "country": "Название страны",
      "amount": "Объем продажи (число)",
      "status": "completed"
    }
  ]
}
```

### Кнопки и их действия

| Кнопка | Callback | Действие |
|--------|----------|----------|
| 🟢/🔴 Автопродажа | `sales_auto` | Переключение состояния |
| 🌍 Продать по странам | `sales_by_country` | Открыть выбор страны |
| 🇷🇺 Страна | `sales_select_country:Russia` | Показать подтверждение |
| ✅ Продать | `sales_execute:Russia` | Выполнить продажу |
| ❌ Отменить | `back_to_sales_country` | Вернуться к странам |
| « Назад | `back_to_sales` / `back_to_main` | Вернуться в меню |

## Поддержка и отладка 📞

Если что-то не работает:

1. **Проверьте файл `sales_state.json`**
   ```bash
   cat admin-bot/data/sales_state.json
   ```

2. **Перезагрузите бота**
   ```bash
   python3 admin-bot/bot.py
   ```

3. **Очистите состояние** (если нужно начать заново)
   ```bash
   echo '{"auto_sales_enabled": false, "sales_log": []}' > admin-bot/data/sales_state.json
   ```

4. **Проверьте логи Python**
   Бот выводит логи в консоль с деталями ошибок.
