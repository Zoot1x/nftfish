```

    └─→ SalesService.get_sales_summary()
    ↓
data/sales_state.json (Persistence)
    ↓
Updated UI with InlineKeyboards
```

## 📦 Структура данных

### sales_state.json

```json
{
  "auto_sales_enabled": boolean,
  "sales_log": [
    {
      "timestamp": "ISO 8601",
      "country": "Country Name",
      "amount": 1.0,
      "status": "completed"
    }
  ]
}
```

### Callback Data Format

```
sales                              → Открыть меню
sales_auto                         → Включить/отключить
sales_by_country                   → Выбор страны
sales_select_country:Russia        → Подтверждение
sales_execute:Russia               → Выполнить продажу
back_to_sales                      → Назад в меню
back_to_sales_country              → Назад к странам
back_to_main                       → На главное меню
```

## 🚀 Как использовать

### Запуск бота

```bash
cd admin-bot
python3 bot.py
```

### Тестирование функций

```bash
python3 << 'EOF'
from utils.sales_service import SalesService

# Проверить текущее состояние
status = SalesService.is_auto_sales_enabled()

# Переключить автопродажу
new_state = SalesService.toggle_auto_sales()

# Записать продажу
SalesService.record_sale("Russia", 1.0)

# Получить статистику
summary = SalesService.get_sales_summary()
EOF
```

### Просмотр истории

```bash
cat admin-bot/data/sales_state.json | python3 -m json.tool
```
