# Команды для запуска с разными ресурсами

## Обычный режим (4GB памяти для Node.js)
```bash
npm run dev
```
- Использует 4GB оперативной памяти для Node.js
- Оптимально для большинства случаев

## Турбо режим (8GB памяти для Node.js)
```bash
npm run dev:turbo
```
- Использует 8GB оперативной памяти
- Принудительная пересборка всех зависимостей (--force)
- Используйте если сайт все еще лагает

## Сборка для продакшена (8GB памяти)
```bash
npm run build
```
- Оптимизированная сборка с 8GB памяти

## Дополнительные опции

### Увеличить память еще больше (например, 16GB)
```bash
NODE_OPTIONS='--max-old-space-size=16384' npm run dev
```

### Проверить использование памяти
```bash
node --expose-gc --max-old-space-size=4096 node_modules/vite/bin/vite.js
```

### Очистить кэш Vite
```bash
rm -rf node_modules/.vite
npm run dev
```

## Что было оптимизировано:

1. **Node.js память**:
   - `--max-old-space-size=4096` - 4GB для dev режима
   - `--max-old-space-size=8192` - 8GB для турбо и билда

2. **Vite конфигурация**:
   - Оптимизация зависимостей (react, react-dom)
   - Разделение на чанки для быстрой загрузки
   - Целевая платформа: esnext (современные браузеры)

3. **NFT загрузка**:
   - Ограничение до 140 NFT вместо 5092
   - Случайный выбор при каждом запуске
